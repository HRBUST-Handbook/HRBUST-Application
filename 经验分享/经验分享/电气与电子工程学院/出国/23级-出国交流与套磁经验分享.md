## 准备建议

### 1. 语言尽早规划

我在大二完成了雅思考试。对于有类似计划的同学，建议提前了解目标项目的语言要求，把备考安排进本科阶段的学习计划。

准备正式申请时，还需要结合申请时间和项目要求，核对语言成绩是否适用。

除了考试，也可以逐步练习：

- 用英语介绍自己的专业背景；
- 说明做过的项目和承担的工作；
- 阅读研究方向相关的英文论文；
- 在交流中表达自己的研究兴趣与问题。

### 2. 保持成绩，清楚展示排名

我的绩点排名位于专业前 5%。准备材料时，建议把成绩和排名信息写清楚，让老师能够快速了解自己的学习情况。

例如，简历中可以说明：

- 本科院校、专业与年级；
- GPA 及其计分标准；
- 专业排名及参与排名的人数；
- 与申请方向相关的主要课程。

排名和成绩应使用能够核实的信息，材料中的表述也要保持一致。

### 3. 套磁邮件围绕具体老师来写

联系过多所学校后，我想把“主动寻找机会”这一点分享给后来者。

准备套磁邮件时，可以先阅读导师主页，了解近期研究方向，再说明自己的背景与申请意向。

| 邮件部分 | 建议写清楚的内容 |
| :--- | :--- |
| **我是谁** | 学校、专业、年级、成绩与语言情况 |
| **为什么联系您** | 对老师哪一项研究感兴趣，与自己的经历有什么联系 |
| **我做过什么** | 相关课程、项目、科研经历及个人贡献 |
| **我希望申请什么** | 项目类型、预计开始时间与参与时长 |
| **希望了解什么** | 是否有合适机会，以及需要补充哪些材料 |

研究兴趣可以从自己理解的问题出发。提到老师的论文或项目时，也应能够说明自己关注的具体内容。

### 4. 联系多所学校时，做好记录

建议建立一张简单的申请记录表，方便跟进：

| 导师与学校 | 研究方向 | 首次联系日期 | 回复情况 | 下一步 |
| :--- | :--- | :--- | :--- | :--- |
| 自行填写 | 自行填写 | 自行填写 | 自行填写 | 自行填写 |

收到回复后，及时记录对方提出的问题、材料要求和后续安排，避免遗漏。
