# 从哈理工到华工：聊聊我这一路的保研经历

先介绍一下自己的情况。

哈尔滨理工大学电气工程及其自动化专业，排名 **2/501**，四级514，六级457。拿过国奖、儒苑、省三好，参加过高校电气与电子创新大赛、信息安全与对抗、蓝桥杯、数学建模等竞赛，有两个DC/DC变换器相关的项目经历，主要负责仿真，没有论文。

今年预推免过了**东北大学、山东大学、华南理工大学**，最后去了华南理工大学电气工程专硕。

其实保研结束之后一直想写点东西，毕竟自己当年也是看着学长学姐的经验一步步走过来的。网上有很多履历很强的保研经验，但站在哈理工电气学生的角度，我更想聊聊自己这几年是怎么过来的，以及一些真正有用的经验。

## 1. 关于排名，真的要尽可能往前冲

先说最重要的：**如果你从大一就有保研的想法，优先把排名搞上去。**

我大一刚入学就想保研，一方面是有985情结，另一方面是自己以后想进电网，觉得读研去一个更好的平台，未来就业可能也会有更多选择。

但那个时候其实什么都不懂，不知道该打什么比赛，也不知道怎么找项目。看到一些学长学姐又是国奖又是竞赛又是科研的，感觉人家什么都会，自己根本不知道从哪里开始。

回头看，最庆幸的一件事，就是自己一直没把专业课成绩落下。

到了真正申请的时候你会发现，排名是最实在的东西。竞赛、项目可以慢慢积累，但排名一旦掉下去，后面想补就很难了。

特别是我们这种本科院校，申请一些985的时候本来就不一定占优势。如果专业排名还不够靠前，那能选择的机会可能就更少了。

当然，不是说排名第二就一定能去985，也不是说后面的同学就没机会。但如果还在大一大二，真的建议先把绩点稳住，不要为了打比赛把课内成绩搞得一塌糊涂。

## 2. 竞赛和项目，其实没必要一开始就想得那么复杂

我本科参加了不少比赛，但说实话，刚开始我也根本没有什么明确的规划。

一开始就是有比赛就尝试参加，慢慢认识一些队友、学长和指导老师，之后有新的比赛或者项目，大家可能又会一起合作。接触得多了，自然也就有了一些机会。

所以如果有学弟学妹问我，大学应该怎么找竞赛、怎么接触老师，我觉得最重要的还是**先参与进去**。

你不一定要一开始就找到特别厉害的老师，或者直接进一个很高端的科研项目。先跟着学长学姐做点事情，参加一次比赛，认识一些愿意一起做事的人，后面可能就有更多机会了。

不过也别为了丰富简历什么比赛都参加。尤其到了大二大三，还是要有所取舍。与其堆一大堆自己说不清楚的经历，不如把一两个项目真正搞明白。

我自己本科没有论文，做的项目主要也是仿真，并没有什么特别拿得出手的硬件成果。但面试之前，我会重新把项目里的拓扑、控制方法、参数设置和仿真结果梳理一遍，至少保证简历上写的东西自己能讲清楚。

**简历可以适当包装表达，但经历千万别乱编。** 老师真要沿着某个技术细节追问，做没做过其实很容易看出来。

## 3. 双非保研985，夏令营没机会也别太早灰心

我夏令营阶段只申请了山东大学。

当时也了解了一些其他学校，明显感觉部分985的夏令营对本科背景要求比较高。对于双非学生来说，有时候不是你完全没有竞争力，而是连参加考核的机会都不一定能拿到。

所以我觉得大家没必要因为夏令营阶段不顺利，就觉得自己后面没希望了。

**预推免真的还有机会。**

但这里有个前提，就是你得提前做好准备。不要等到学校通知出来、发现自己可以报名了，才开始重新学专业课。

我自己是八月底才开始比较集中地准备专业课，现在回头看，其实时间还是有点紧。如果学弟学妹有明确的保研目标，完全可以更早开始，每天看一点，不用等到最后一个月再突击。

至于选学校，我觉得没必要因为双非就完全不敢报985，但也不要只盯着最热门的几所。结合自己的排名、英语、竞赛和研究方向，适当拉开梯度，多关注不同学校的预推免通知。

## 4. 专业课真的比想象中重要，尤其不要只背题库

这是我整个保研过程中感受最深的一点。

我准备专业课的时候，主要复习电力系统分析、电机学、电力电子、高电压这些科目，也看了继电保护和自动控制的一些知识。

我的方法比较简单：先复习基础概念，再把买的题库和学长学姐分享的面试题交给ChatGPT，让它按照真实面试的方式提问，自己练习怎么回答。

但后来我发现，**只靠背题库是真的不够的。**

举个我自己的例子。

山东大学面试时，我抽到的专业课题目是网损，以及为什么无功补偿能够减少网损。

乍一看是不是很基础？但老师会顺着你的回答一直往下问。

为什么说有无功损耗？有哪些无功补偿方式？变压器变比具体怎么调？无功电源有哪些？电容器和静止无功补偿器有什么区别？

你每说出一个概念，老师都可能继续追问。

我那场回答得其实挺一般，有些问题答得也不好。也是经历了这场面试才更加意识到，很多专业课知识平时觉得自己会了，其实只停留在记住定义的程度。

华工就更不用说了，题目范围很广，有些还考得挺细。我遇到了辐射型配电网潮流、继电保护、自动控制等问题，其中有些内容确实不熟悉。

所以建议大家复习的时候，尤其是电分这种课程，**多问自己几个为什么，而不是记住一句标准答案就直接翻篇。**

例如学潮流计算，至少得真正明白它在算什么、输入输出是什么、不同方法为什么适用于不同网络。只会背“牛拉法收敛速度快”这样的结论，老师稍微往深处问就容易卡住。

还有一个建议，专业课也不用一味追求偏题怪题。先把那些最基础、最常见的问题理解透彻，比到处搜特别冷门的面试题更有意义。

## 5. 英语没那么突出，也可以试试，但别完全不准备

我自己的四六级成绩其实挺普通的，四级514，六级457。

所以如果有同学英语成绩不是特别高，也不用一上来就觉得自己肯定申不上好学校。当然，英语成绩更高肯定是有优势的，能早点把六级考高就尽量早点考。

我面试之前主要准备了自我介绍、研究生规划、研究兴趣、团队合作等常见问题。

这些问题真没必要写得特别高级，能自然流畅地表达清楚就可以。

但**专业英语一定要单独准备**。

尤其是华工这种有英文文献翻译的学校。我华工面试时抽到的是新能源相关的英文文献，要先朗读再翻译。

说实话，我那段翻译得挺差的，很多地方根本没看懂，只能把自己理解到的内容零零散散地说出来。

所以这方面我也没什么特别成功的经验，反而想提醒大家：如果目标学校考文献翻译，还是早点积累专业词汇，平时多看一些电气相关的英文段落，别像我一样到了现场才发现自己准备得不够。

## 6. 关于面试，我觉得真的没必要追求完美

我一共参加了三场面试。

9月16日东北大学，18日山东大学，20日华南理工大学。

东北大学整体比较平稳，山东大学喜欢围绕知识点继续追问，华工的考查范围则比较广，难度也更大。

实际上，我并不是三场都发挥得很好。

山大专业课有些问题没回答好，华工英语翻译发挥得不理想，专业课和自动控制也有不少不会的内容。

华工有几道题我甚至没听懂，最后只能和老师说自己不会。

但是最后三所都通过了。

我当然不知道老师具体是怎么评分的，也不敢说面试表现不重要。但至少从我自己的经历来看，**一两道题回答不好，真的不意味着整场面试就没希望了。**

尤其是遇到连续追问的时候，不要因为前面一道不会，后面整个人就开始紧张、乱答。

会的就尽量把原理解释清楚，不会的想一想，实在不知道就坦诚承认。最忌讳的是明明不会，还硬往自己不熟悉的地方扯，反而给自己挖更多坑。

另外，面试的时候可以尽量保持正常交流，不要全程低头背答案。老师问问题，你认真听，回答的时候看着老师，保持基本的交流感就好。

## 7. 关于联系导师和最后的选择

我觉得如果有比较明确的目标学校和研究方向，提前了解导师还是挺有必要的。

我自己是通过哈理工本科老师的介绍，比较早就联系到了华工的意向导师。前期通过微信交流，老师给了我很多鼓励，面试的时候也有机会线下见面。

这也是我最后选择华工的一个重要原因。

所以大家平时如果有机会，可以多和本科老师交流。有些老师可能认识其他学校的老师或者以前毕业的学生，能够提供一些信息。当然，最终能不能得到导师认可，还是要看个人情况和实际交流。

我最后拿到东北大学、山东大学和华南理工大学三个预推免通过结果后，选了华工。

原因其实也很简单：我以后想去南方电网，广州在地域上比较符合自己的就业规划，离湖南老家也更近，而且自己对意向导师的印象很好，所以没必要去华科了，因为去华科最后也是去南方电网，可能这三年会非常累，而华工就比较舒服了，跟着个梦导，老师给钱多，能推荐工作，和学生关系好，去向也挺好。

因此，我觉得选学校也没有必要只看排名。**学校平台、导师、研究方向、就业地区，以及自己愿不愿意在那里生活两三年，都值得考虑。**

## 8. 最后想说几句

如果再回到大一，我觉得自己最应该做的，依然是认真学好专业课，同时多参加一些有意义的竞赛和项目，尽早了解保研的信息。

有时候我们会觉得自己是双非学生，和那些985、211的同学相比没有什么优势，所以连尝试都不敢。

但其实很多事情只有真正去做了，才知道有没有机会。

我大一的时候也不知道后来会遇到哪些队友、参加哪些比赛、接触哪些老师，更不可能提前规划好最后去哪所大学。

大学这几年，很多机会就是在不断尝试中慢慢出现的。

当然，也不是说有了排名和竞赛就一定能保研到985。每个人的条件、申请年份和考核情况都不一样。但至少希望大家不要因为本科院校的标签，就提前给自己设限。

如果你还在大一大二，那就先把成绩搞好，多去尝试；如果已经大三，准备开始申请了，也不用一直纠结过去哪些地方没做好，把能准备的东西尽量准备充分就行。

最后也感谢本科期间遇到的老师、学长学姐和一起参加比赛的队友。没有这些经历和帮助，我应该也很难走到现在。

从哈尔滨出发，先到沈阳，再到济南，最后去了广州。

**见识了东北的风景，也该一路向南了。**

**最后感谢哈理工，感谢这里的老师，志同道合的朋友们，虽然也时常调侃，不过理工真是个很好的平台，尤其是了解到高中同学他们学校的竞争，和最后去向，理工简直性价比拉满，理工不会辜负你的。**
