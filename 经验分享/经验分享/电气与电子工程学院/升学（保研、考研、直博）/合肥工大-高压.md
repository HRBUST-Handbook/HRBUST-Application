## 专业课程学习

### 认真对待专业课与高学分课程

对于有保研计划的同学，我建议认真对待每门课程，尤其是**专业课程和学分较高的课程**，例如高等数学、高电压绝缘技术等，尽量争取较高的成绩。

生产实习等需要撰写心得、报告的实践课程，也值得投入时间认真完成。不要因为它们主要以报告形式考核，就降低对自己的要求。

### 不要因为一学期的发挥而轻易放弃

如果某个学期的成绩不够理想，也希望大家不要因此直接放弃。

本科前三年的学习是一个持续积累的过程。尽可能认真准备每一次考试、完成每一项课程任务，把后续能够争取的成绩拿到手。

**一次发挥不理想之后，仍然可以继续调整自己的学习方法和状态。**

## 科研与竞赛

这方面我自己的经验不算多，但有一点想提醒大家：

> **写进保研简历的竞赛经历，最好都是自己有把握、能够讲清楚的。**

老师可能会根据简历中的竞赛经历继续提问，并延伸到相关的专业知识。

准备简历时，建议提前梳理：

- 自己在比赛中具体承担了什么工作；
- 项目使用了哪些方法和专业知识；
- 哪些部分是自己独立完成的；
- 如果被进一步追问，能否解释清楚其中的原理。

## 保研准备

### 我的情况：开学后才知道获得保研资格

我是在开学后才知道自己获得了保研资格，整个过程确实带有一些幸运的成分。

如果大家能够较早判断自己有希望进入保研名额范围，建议在**大四前的暑假**就开始准备：

| 准备事项 | 建议内容 |
| :--- | :--- |
| **专业课复习** | 梳理本科核心课程，准备基本概念与原理问答 |
| **夏令营** | 关注目标院校通知，提前准备申请材料 |
| **个人简历** | 整理课程成绩、科研竞赛经历及个人贡献 |
| **自我介绍** | 分别准备中文与英文版本 |

专业课准备可以结合申请方向安排重点，同时兼顾本科基础课程。

## 院校面试经历

我参加过以下三所院校的面试：

| 院校 | 面试形式 | 主要环节 |
| :--- | :--- | :--- |
| **河北工业大学** | 线下面试 | 中文自我介绍、专业课抽题、专业英语 |
| **合肥工业大学** | 单机位线上面试 | 综合素质问题、编号选取专业题 |
| **中国矿业大学（徐州）** | 线下面试，约 15 分钟 | 英文自我介绍、限时专业文段翻译、教师提问 |

### ① 河北工业大学

面试主要分为以下几个环节：

| 环节 | 本次经历 |
| :--- | :--- |
| **递交简历** | 进入教室后，先向老师提交简历 |
| **中文自我介绍** | 进行约 **5 分钟的口头自我介绍** |
| **现场抽题** | 从面前的纸箱中抽取 **2 道专业课题和 1 道专业英语题** |
| **回答问题** | 对抽到的题目逐一作答 |

专业课题目的范围涵盖：

- 电路；
- 模拟电子技术与数字电子技术；
- 电机学；
- 电力系统；
- 电力电子技术。

**准备建议：**除高压方向的知识外，也要复习其他本科核心课程，练习用自己的话解释基本概念和原理。

---

### ② 合肥工业大学

本次采用的是**单机位线上面试**，老师主要提了两个问题：

| 问题 | 本次考核内容 |
| :--- | :--- |
| **第一个问题** | 综合素质类问题 |
| **第二个问题** | 在 **1—15 号**中选择一个编号，回答对应的专业问题 |

**我这次面试没有被问到英语问题。**

准备时可以提前练习清楚、完整地回答问题，也要熟悉线上面试所使用的设备和网络环境。

---

### ③ 中国矿业大学（徐州）

我参加的这一届采用了大家常说的“海面”形式。按我当时了解到的情况，完成网申后即可进入面试。

参加线下面试的人比较多，我个人感觉现场安排有些混乱。整个面试时长约 **15 分钟**，主要流程如下：

| 顺序 | 面试环节 | 具体内容 |
| :---: | :--- | :--- |
| 1 | **英文自我介绍** | 用英语介绍自己的基本情况 |
| 2 | **专业英文翻译** | 自己抽取专业英文文段，并在规定时间内完成翻译 |
| 3 | **教师提问** | 约 **6 位老师依次提问** |

对我来说，这场面试整体有一些**压力面**的感觉，需要在连续提问中保持状态。

**准备建议：**

- 提前练习英文自我介绍，熟悉自己的表达；
- 积累电气专业常见英文词汇；
- 练习在限定时间内理解和翻译专业文段；
- 面对连续提问时，尽量先理清思路，再逐项回答。
