## 提前联系导师

**建议从 5 月左右开始了解课题组、整理简历，并提前联系意向导师。**

联系前，可以先了解老师的研究方向，再结合自己的专业背景、科研经历和兴趣说明申请意向。专业课复习也建议同步开始，为可能到来的导师交流做好准备。

| 建议阶段 | 主要准备内容 |
| :--- | :--- |
| 5 月左右 | 了解课题组方向，整理简历，联系意向导师 |
| 联系导师前后 | 梳理科研经历，结合报考方向复习专业课 |
| 导师交流前 | 准备排名、英语成绩及项目介绍，练习专业问答 |
| 学院面试前 | 完善 PPT，练习英文表达和限时汇报，核对材料 |

## 准备重点

### 1. 排名与英语：建议提前整理清楚

就我接触到的情况而言，**老师比较关注本科排名和英语水平**。

建议提前整理好：

- 专业排名、排名人数及对应时间；
- 成绩单和主要专业课成绩；
- 英语考试成绩；
- 英文介绍及科研经历的英文表达。

这些信息尽量在简历中写清楚，交流时也要能够准确说明自己的情况。

### 2. 专业基础：结合意向方向复习

建议提前复习**电机学、电力电子、电力系统**等课程，再根据意向导师的研究方向调整侧重点。

下面是用于组织复习的基础知识范围：

| 课程 | 可以重点梳理的内容 |
| :--- | :--- |
| **电机学** | 变压器、异步电机和同步电机的基本原理；等效电路、功率与转矩关系 |
| **电力电子** | 整流、逆变、DC/DC 电路的工作原理；开关器件、PWM 与基本控制思路 |
| **电力系统** | 潮流与短路基础；电压和频率调节；稳定性的基本概念 |

具体复习侧重应结合报考方向。例如，申请电力电子相关方向时，可以进一步梳理变换器和控制基础；申请电力系统相关方向时，则可以更多关注系统分析、运行与稳定性。

**以上是复习建议，具体问题还会与导师方向及个人经历有关。**

### 3. 科研经历：写进材料的内容，自己都要掌握

科研经历建议从背景、方法到结果完整梳理。交流时，老师可能围绕材料中的某个细节继续追问。

| 需要掌握的部分 | 建议能够回答的问题 |
| :--- | :--- |
| 研究背景 | 为什么研究这个问题？ |
| 技术方法 | 为什么选择这种方法？ |
| 个人贡献 | 自己具体完成了哪些工作？ |
| 仿真或实验 | 参数如何设置，结果如何解释？ |
| 局限与改进 | 当前还有哪些不足，下一步如何推进？ |

涉及团队合作时，也要能说明整个项目的思路，以及自己承担的部分。

### 4. 竞赛经历：本次基本没有被追问

**我这次面试中，竞赛经历基本没有被问到。**

这是个人经历，供大家分配准备时间时参考。建议先把专业基础和科研内容复习扎实，材料中列出的竞赛经历也应能说明自己的实际工作和收获。

### 5. PPT 汇报：练习完整计时

约 8 分钟的汇报，需要提前练习内容取舍。

| 汇报部分 | 建议重点 |
| :--- | :--- |
| 个人介绍 | 简洁交代专业背景和主要经历 |
| 英文汇报 | 熟悉专业词汇，表达清楚、自然 |
| 研究工作 | 讲清问题、方法、个人贡献与结果 |
| 科研规划 | 说明研究兴趣及下一步学习计划 |

## 个人感受

### 导师交流时，专业问题的压力比较大

对我来说，前期与导师交流时，专业知识和科研细节问得比较细，确实有“压力拉满”的感觉。

这也让我意识到，简历和 PPT 中的每一段经历，都值得提前认真复盘。尤其是自己写出的专业术语、方法和结果，最好都能用自己的话解释清楚。

### 正式学院面试时，反而放松了不少

经历前期导师交流后，我参加学院面试时，心理压力比预期小了一些，现场表达也更放松。

有些回答带着临场发挥的成分，但前面梳理过自己的经历，交流时也更容易讲出自己的理解。学院面试仍然需要按要求准备，尤其要熟悉 PPT 和科研规划。
